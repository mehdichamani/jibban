# جیب‌بان (JibBan) 💳

سامانه هوشمند و جامع حسابداری شخصی، مدیریت دنگ و پردازشگر پیامک‌های بانکی ایران.

## معماری و ساختار مخزن (Monorepo)

- `apps/web`: وب‌اپلیکیشن مدرن (React + Vite + TailwindCSS + PWA) برای استفاده در کامپیوتر و موبایل.
- `apps/worker`: بک‌اند سرورلس کلادفلر (Cloudflare Workers + Hono + D1 SQLite + KV).
- `apps/android`: اپلیکیشن اندروید سبک کاتلین (خواندن خودکار پیامک در پس‌زمینه + وب‌ویو داخلی).
- `packages/sms-parser-ir`: موتور تفکیک و پردازش پیامک‌های بیش از ۲۶ بانک ایرانی + فال‌بک معنایی.
- `packages/debt-engine`: موتور ریاضی محاسبات و ساده‌سازی تسویه دنگ (اقتباس‌شده از Spliit).
