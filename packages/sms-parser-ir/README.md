# @jibban/sms-parser-ir

پکیج مستقل، فوق‌سریع و بدون وابستگی جانبی (Zero Runtime Dependencies) جهت پردازش و استخراج هوشمند اطلاعات پیامک‌های بانکی ایران. این بسته هسته اصلی پردازشگر پیامک در سامانه حسابداری جیب‌بان (JibBan) است.

## ویژگی‌ها

- **پشتیبانی از ۲۷ بانک و موسسه مالی ایران:**
  - بانک‌های دولتی: ملی، سپه (شامل بانک‌های ادغامی: انصار، قوامین، مهر اقتصاد، حکمت ایرانیان، کوثر)، کشاورزی، مسکن، پست‌بانک، توسعه تعاون، توسعه صادرات.
  - بانک‌های خصوصی و تجاری: ملت، صادرات، تجارت، پاسارگاد، سامان، پارسیان، اقتصاد نوین، آینده، شهر، دی، سینا، گردشگری، کارآفرین، سرمایه، خاورمیانه، ایران‌زمین، رفاه کارگران.
  - نئوبانک‌ها و قرض‌الحسنه: بلوبانک (Blu)، قرض‌الحسنه رسالت، قرض‌الحسنه مهر ایران.
- **موتور فال‌بک عمومی (Generic Fallback Engine):** در صورت تغییر فرمت پیامک هر بانک یا دریافت پیامک از موسسات ناشناس، موتور بر مبنای تحلیل الگوها اطلاعات تراکنش را استخراج می‌کند.
- **تبدیل تضمینی مبالغ به تومان:** مبالغ ریالی بانک‌ها به صورت خودکار با حذف صفر انتهایی به تومان تبدیل شده و مبالغ بانک‌های تومانی (مانند بلوبانک) بدون تغییر حفظ می‌شوند.
- **پشتیبانی کامل از ارقام فارسی و عربی (`۰-۹` و `٠-٩`).**
- **استخراج و تبدیل تاریخ شمسی به استاندارد ISO 8601.**
- **فیلتر هوشمند پیام‌های نامربوط (کدهای تایید، رمز پویا، پیام‌های تبلیغاتی و شخصی).**

## نحوه نصب

```bash
pnpm add @jibban/sms-parser-ir
```

## نحوه استفاده

```typescript
import { parseBankSms } from '@jibban/sms-parser-ir';

const sms = `بانک ملی ایران
برداشت از حساب: 0105891234
مبلغ: 2,500,000 ریال
مانده: 14,200,000 ریال
1403/08/01 11:30
پایانه: فروشگاه کوروش`;

const result = parseBankSms(sms);
console.log(result);
/*
{
  isBankSms: true,
  bankName: 'ملی',
  type: 'debit',
  amount: 250000, // مبلغ نرمال‌شده همیشه به تومان
  balance: 1420000,
  accountNumber: '1234',
  transactionDate: '2024-10-22T11:30:00+03:30',
  description: 'فروشگاه کوروش',
  rawText: '...'
}
*/
```
