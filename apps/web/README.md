# @jibban/web

وب‌اپلیکیشن دسکتاپ و موبایل (React PWA) سامانه جیب‌بان (JibBan) با طراحی راست‌چین (RTL)، تایپوگرافی وزیرمتن و رابط کاربری گلس‌مورفیسم مدرن.

## قابلیت‌های پیاده‌سازی‌شده

1. **داشبورد تراکنش‌ها (Transactions Feed):**
   - کارت‌های خلاصه وضعیت مالی (موجودی کل، واریزی‌های ماه، مخارج ماه).
   - فید تراکنش‌ها با برچسب بانک‌ها (بلو، ملی، سامان، ملت و...)، نوع واریز/برداشت و مبلغ به تومان.
   - **دکمه جادویی «اشتراک در دنگ» (To Split):** اتصال آنی هر تراکنش پیامکی به هزینه گروهی.
   - **شبیه‌ساز زنده پیامک بانکی:** امکان تست درجا با پیامک‌های نمونه بیش از ۲۶ بانک یا الصاق پیامک شخصی.

2. **مدیریت دنگ (Splitwise Tab):**
   - نمایش تراز خالص لحظه‌ای («شما ۱۸۵,۰۰۰ تومان طلبکارید / بدهکارید»).
   - بخش **تراکنش‌های بهینه تسویه** تولیدشده توسط الگوریتم Spliit پکیج `@jibban/debt-engine`.
   - دکمه‌های «ثبت تسویه حساب» و «ثبت خرج جدید گروهی».

3. **گزارش‌گیری ماهانه (Analytics):**
   - تفکیک مخارج بر اساس دسته‌بندی با نوارهای درصد و مبالغ تومانی.
   - شاخص سهم دسته‌بندی با بالاترین هزینه و نسبت دخل به خرج.

4. **تنظیمات و امنیت (Settings & Sync):**
   - مشاهده و کپی کلید اختصاصی `Sync Token` برای اتصال اپ کاتلین اندروید.
   - تنظیم آدرس ورکر کلادفلر و امکان بازنشانی دیتا.

## دستورات اجرایی

```fish
# اجرای سرور توسعه محلی
pnpm --filter @jibban/web dev

# ایجاد بیلد بهینه برای دیپلوی روی Cloudflare Pages
pnpm --filter @jibban/web build
```
